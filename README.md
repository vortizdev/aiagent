# AI Agent

AI Agent is a Python-based project designed to facilitate various AI-related tasks, including file management, execution of Python scripts, and handling system prompts. This project aims to provide a robust framework for developing AI applications with a focus on modularity and ease of use.

## Features
- **File Management**: Efficiently read and write files with error handling.
- **Script Execution**: Safely execute Python scripts with built-in error management.
- **Modular Design**: Organized structure for easy maintenance and scalability.

## Installation
To install the AI Agent, clone the repository and install the required dependencies:

```bash
git clone https://github.com/vortizdev/aiagent.git
cd aiagent
pip install -r requirements.txt
```

## Usage
To use the AI Agent, simply import the necessary modules in your Python scripts:

```python
from aiagent import get_file_content, write_file, run_python_file
```
